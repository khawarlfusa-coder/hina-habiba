# Sana Khawan Hina Habiba - Official Artist & Naat Portfolio Website

An elegant, spiritually designed, mobile-responsive portfolio and Mehfil booking inquiry website created for the renowned Naat Khawan **Hina Habiba** and her official platform **HH Production (@HinaProduction-o6e)**.

---

## 🌟 Key Features

1. **Official YouTube Channel Integration**:
   - Direct integration with **[@HinaProduction-o6e](https://www.youtube.com/@HinaProduction-o6e)**.
   - Highlights her trending 2026 studio release **"Sarkar Ki Aamad"** with Javerya Fatima, Hijab Fatima, and Muryam Zeshan.
   - Direct watch and subscribe buttons across all sections.

2. **Mehfil-e-Naat Inquiry & Booking Portal**:
   - Comprehensive event reservation form for Milad celebrations, Ladies-only Mehfils, Seerat conferences, and family gatherings.
   - Auto-generated inquiry reference tracking (e.g., `#HH-2026-XXXX`).
   - **Direct WhatsApp Dispatch**: 1-click button that formats all organizer input into a structured WhatsApp message sent to management.

3. **Curated Kalaam Repertoire & Filter System**:
   - Interactive category filtering: *All Kalaams, Milad-e-Mustafa, Soulful Naats, Hamd & Manqabat, Collaborations*.
   - Includes famous releases: *Barhween Ka Noor*, *Sukoon Paya*, *Ilahi Koi Aesa Intezam Ho Jaye*, *Assubhu Bada*, *Madni Dar Diyan Yadaan*, *Hasnain Da Nana*, *Shan-e-Muhammad*, and *Utha Do Parda*.
   - Simulated audio player preview with animated waveform equalizer and persistent floating player toast.

4. **Direct Contact & Management Channels**:
   - Official inquiry email (`hinaproduction.official@gmail.com`) with 1-click clipboard copy.
   - Management phone / WhatsApp coordination hotline.
   - Interactive FAQ accordion for booking timelines, logistics, and sound system requirements.

5. **Aesthetic & Spiritual Design**:
   - Palette: Deep Emerald Green, Midnight Obsidian, Champagne Gold accents, and Warm Pearl.
   - Subtle starfield background and Bismillah calligraphic emblem.
   - 100% responsive across mobile phones, tablets, laptops, and ultra-wide screens.

## 🚀 How to Run & View Locally

### Option 1: Direct Browser Access
Simply double-click or open `index.html` in any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Run with Node.js Server
Open a terminal in this folder and run:
```bash
node local-server.js
```
or simply double click `start-server.bat`.

Then visit:
```
http://localhost:8080/
```
